# Agents Working Group

This working group (WG) focuses on the deployment, maintenance, and operationalization of autonomous agentic workflows within Kubeflow.  While the [wg-ml-experience](/wg-ml-experience/charter.md) governs direct-to-IDE developer integrations, this WG focuses on the autonomous agent experience.  Building the infrastructure and tooling that allows agents to independently execute operational tasks (e.g., "investigate this Spark app") and/or serve as integrated solutions as part on Kubeflow.

The [charter](charter.md) defines the scope and governance of the Agents Working Group.
